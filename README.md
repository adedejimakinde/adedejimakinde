# Adedeji Makinde

I am a Python developer and Machine Learning Engineer. I build web backends and APIs with Django, PostgreSQL and PostGIS and I build NLP tools and datasets for African languages with a focus on Yorùbá. I do my language research through the [Masakhane](https://www.masakhane.io) community.

I am open to remote roles in Python Development, Machine Learning Engineering and Developer Relations.

## Projects

**Classnode**

A multi-tenant school management platform. I built its bus-routing component as a spatial decision support system: student locations are grouped with K-Means clustering, stored and queried with PostGIS and served through a Django REST API.

**[yotext](https://pypi.org/project/yotext/)**

A Python library for Yorùbá text normalisation and diacritic restoration. Published on PyPI (v0.3.0) with a companion dataset on [Hugging Face](https://huggingface.co/adedejimakinde) and a deployed live demo on [Render](https://yotext-demo.onrender.com/).

**Yorùbá sentiment analysis**

Compares zero-shot LLM prompting with fine-tuned multilingual models (AfriBERTa, AfroXLMR, mBERT, XLM-R) on a labeled Yorùbá corpus. Results are prepared for publication.

**Yorùbá retrieval benchmark** (in progress)

A set of 300 queries written by native speakers to test how retrieval systems handle Yorùbá text, including missing or inconsistent diacritics. Built with volunteer annotators for submission to AfricaNLP.
